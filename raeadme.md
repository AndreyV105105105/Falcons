# Secure Pass & Vault (Генератор паролей)

Веб-приложение для генерации сложных паролей с гибкими настройками и облачным криптографическим хранилищем. [cite_start]Проект разрабатывается в рамках кейса «Разработка приложения для генерации сложных паролей»[cite: 2].

## О проекте
[cite_start]Приложение решает прикладную проблему создания устойчивых паролей под разные требования[cite: 7, 9]. [cite_start]В отличие от простых генераторов, наша система предлагает SaaS-подход: пользователи могут регистрироваться, сохранять любимые настройки (пресеты) [cite: 31] и безопасно хранить историю генераций. 
Все сохраненные пароли шифруются на бэкенде с использованием уникального «мастер-ключа» пользователя, который нигде не сохраняется.

## Архитектура и Стек технологий
Проект построен по микросервисной (serverless) архитектуре в виде монорепозитория:
* [cite_start]**Frontend:** React (SPA) — папка `/frontend` [cite: 57]
* [cite_start]**Backend:** Python / Flask (Serverless функции на Yandex Cloud API Gateway) — папка `/backend` [cite: 157]
* [cite_start]**База Данных:** PostgreSQL (Managed Service) — папка `/database` [cite: 160]
