# Secure Pass & Vault (Генератор паролей)

Веб-приложение для генерации сложных паролей с гибкими настройками и облачным криптографическим хранилищем. Проект разрабатывается в рамках кейса «Разработка приложения для генерации сложных паролей».

## О проекте
Приложение решает прикладную проблему создания устойчивых паролей под разные требования. В отличие от простых генераторов, наша система предлагает SaaS-подход: пользователи могут регистрироваться, сохранять любимые настройки (пресеты) и безопасно хранить историю генераций.
Все сохраненные пароли шифруются на бэкенде с использованием уникального «мастер-ключа» пользователя, который нигде не сохраняется.

## Архитектура и Стек технологий
Проект построен по микросервисной (serverless) архитектуре в виде монорепозитория:
* **Frontend:** React (SPA) — папка `/frontend`
* **Backend:** Python / Flask (Serverless функции на Yandex Cloud API Gateway) — папка `/backend`
* **База Данных:** PostgreSQL (Managed Service) — папка `/database`
